## 🔍 Features

### Search & Filter:
- ✅ Search by name, tags, or mood
- ✅ Filter by category
- ✅ Get images by mood
- ✅ Get images by category
- ✅ Get random image
- ✅ Get compatible image based on composition

### Image Properties:
Each image includes:
- **ID**: Unique identifier
- **Name**: Descriptive name
- **Category**: architectural, 3d, studio, glass, paper, tech, editorial, abstract
- **Tags**: Multiple searchable tags (3-5 per image)
- **Source**: High-res 2048x2048 URL
- **Dimensions**: 2048x2048 pixels
- **Dark/Light**: Boolean for contrast detection
- **Busy Level**: Visual complexity indicator
- **Mood**: Array of compatible moods (2-3 per image)

## 🚀 Usage

### In Design Engine:
1. Open Design Engine
2. Select "Image" background type
3. Go to Images tab
4. Search or filter by category
5. Click any image to apply
6. Generate variations with different images

### In Editor:
1. Click "Images" tab in left panel
2. Browse 60 premium backgrounds
3. Search by keyword (e.g., "glass", "dark", "minimal", "chrome")
