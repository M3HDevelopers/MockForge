## 🚀 How to Access New Features:

### **Tech Stack Visualizer:**
1. Open Design Engine
2. Generate a design with icons enabled
3. Icons will automatically arrange around devices
4. Or use `addTechStackIcons(['React', 'Node', 'TypeScript'])`

### **Icon Materials:**
1. Select an icon on canvas
2. Right panel → Material section
3. Choose material (Glass, Glossy, Metallic, etc.)
4. Add gradient if needed

### **Icon Clustering:**
1. Add multiple icons
2. Click "Auto Cluster" button
3. Icons arrange in smart grid pattern

### **Icon Placement Modes:**
1. Select icon
2. Right panel → Placement mode
3. Choose mode (Around device, Behind device, Orbit, etc.)
